# Post-v1 — evidence-gated

Staged work, not dropped work. **Every item here names the gate that unlocks
it** — a measurement, a field failure, a written licence, an engagement outcome.
The tier records *when*; the gate records *why then*. An item with no gate does
not belong in this tier: it is either v1 work or icebox.

Owner directives land here when the founding review (2026-08-08) or a later cold
pass demoted them on evidence. A demotion is never a judgement on worth — it is
a statement that the thing that would prove the item out has not happened yet.

Two items carry a **🎯 owner ruling outstanding**: the platform-tier question
(does the hybrid shell come into v1?) and the marine-staging question (do marine
layers join the v1 phases?). The 2026-08-15 cold pass
([`../../reviews/2026-08-15-1033-platform-tier-and-marine-staging.md`](../../reviews/2026-08-15-1033-platform-tier-and-marine-staging.md))
**decoupled** them — neither waits on the other.
