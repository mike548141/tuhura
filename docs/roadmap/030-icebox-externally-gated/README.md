# Icebox — externally gated

Items whose unlock is an event **outside our control**: a platform vendor's
discretionary approval, a dataset or model that does not exist anywhere yet, an
unreleased API. No amount of work here moves the gate.

They stay on the board rather than being deleted because the reasoning is worth
keeping — an idea that was examined and parked with grounds is cheaper to
re-open than one that has to be rediscovered. Re-evaluate when the external
condition visibly changes, not on a schedule.
