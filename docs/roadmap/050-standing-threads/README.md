# Standing threads — options that may never open

Long-running strands that sit **off every critical path**. Nothing in v1 is
allowed to depend on one: a feature gated on an outreach reply is an *option*,
not a plan, and the roadmap says so at the point the option is recorded.

They differ from post-v1 items in that there is no single unlocking event to
name — they are ongoing obligations (keeping a table current) or open-ended asks
(a licence conversation that may simply never be answered).
